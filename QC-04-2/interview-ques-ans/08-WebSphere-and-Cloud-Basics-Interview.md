# WebSphere and Cloud Basics — Interview Questions & Answers

---

## 1. What is WebSphere Application Server?

**Answer:**
WebSphere Application Server is an enterprise application server from IBM used to run Java-based web and enterprise applications. It provides a managed runtime environment with support for deployment, security, transactions, and scalability.

---

## 2. What is the role of an application server like WebSphere?

**Answer:**
An application server provides the runtime environment needed for enterprise applications to run reliably. It manages application execution, server resources, deployment, security, and other enterprise features.

---

## 3. What is WebSphere architecture in simple terms?

**Answer:**
In simple terms, WebSphere architecture may include application servers that run applications, nodes that host those servers, clusters for scalability and failover, and in larger setups a deployment manager for central administration.

---

## 4. What is application deployment?

**Answer:**
Application deployment is the process of making an application available on a target server or environment so that users can access it. In Java enterprise environments, this often involves deploying WAR or EAR files.

---

## 5. What is cloud computing?

**Answer:**
Cloud computing is the delivery of computing resources such as servers, storage, databases, and software over the internet. Instead of managing everything locally, organizations use resources provided by cloud platforms.

---

## 6. What is the difference between IaaS, PaaS, and SaaS?

**Answer:**
- **IaaS** provides infrastructure like virtual machines and storage
- **PaaS** provides a managed platform where developers deploy applications without managing the full infrastructure
- **SaaS** provides ready-to-use software delivered over the internet

The difference mainly depends on how much the provider manages versus how much the customer manages.

---

## 7. Can you give examples of cloud providers?

**Answer:**
Yes. The major cloud providers are:

- AWS
- Microsoft Azure
- Google Cloud Platform

All three provide services for compute, storage, networking, databases, and more.

---

## 8. What are the benefits of cloud computing?

**Answer:**
The main benefits are:

- scalability
- flexibility
- faster provisioning
- reduced upfront infrastructure cost
- easier access to managed services

Cloud helps organizations move faster and scale more easily.

---

## 9. What is the difference between on-premise and cloud deployment?

**Answer:**
In on-premise deployment, the organization owns and manages the hardware and infrastructure. In cloud deployment, the infrastructure is provided by a cloud vendor over the internet. Cloud usually offers more flexibility and easier scaling.

---

## 10. How are WebSphere and cloud concepts connected in enterprise environments?

**Answer:**
They are connected because enterprise applications that traditionally ran on application servers like WebSphere can now also be hosted in cloud environments. So understanding both helps in modernizing and deploying enterprise applications more effectively.
